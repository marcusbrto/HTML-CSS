Detail e summary

O que é o elemento details?

O elemento <details> é usado para criar um widget interativo que pode ser expandido ou recolhido pelo usuário. Ele é frequentemente utilizado para ocultar ou mostrar informações adicionais, como detalhes de um produto, perguntas frequentes, ou qualquer conteúdo que possa ser opcional para o usuário.

Como usar o elemento details?

Para usar o elemento <details>, basta envolver o conteúdo que você deseja ocultar ou mostrar dentro da tag. O elemento <summary> é usado para definir o título ou a descrição do conteúdo oculto. Quando o usuário clicar no resumo, o conteúdo dentro do <details> será exibido ou ocultado.

Quais são os atributos do elemento details?

O elemento <details> suporta os seguintes atributos:

  • open: Define se o conteúdo do detalhe está visível ou oculto.
  • id: Especifica um identificador único para o elemento.
  • class: Especifica uma ou mais classes para o elemento, permitindo a aplicação de estilos CSS.
